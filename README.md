# 5E-Shikayaku-Database-for-Obsidian
### これはなに！？
これは5E私家訳データベース！このリポジトリ(あるいは保管庫)は、私青桃書房が私家訳して来た5E互換文書の内容をObsidianで参照できるように変換したものだ！全文書はマークダウン+Obsidianの追加記法で記述され、特技やクラスといったデータはそれぞれタグ付けされたうえで個別ファイル(ページ)になっている(ただし、同じ周囲のデータは同じフォルダにまとめられている)。これによって、ObsidianのBaseプラグインなどを活用して5E互換のデータを色々な条件で並び変えたり検索したりできる！また、自分の自作データを既存データと同じフォーマットで作ればデータベースに追加して以降同じように参照検索できる！他にも独自の便利(かもしれない)要素がてんこ盛りなので、ちょっといじってみてよ！

### 使い方！
このデータベースはObsidianで使う前提に作られているので、まずは[Obsidian](https://obsidian.md/)をインストールしてくれ！
インストールできたらこのリポジトリをダウンロードして展開し、Obsidianで保管庫として開く！プラグインを信頼しますかとかなんとか聞かれたら(青桃書房を全く信用していない場合を除き)信頼すること！プラグインが読み込まれたら、おめでとう！君は5E私家訳データベースを利用できるようになったよ！

### 注意！
このデータベースはまだ制作途中で不完全だ！今後かなりの頻度で更新されるだろうから、こまめにアップデートしてくれよな！
